# 走行評価メモ

車両の実走評価中に、発生事象の「種類」を選んで音声でメモを残すための iPhone 向け Web アプリです。
録音した音声は **端末内の OSS 音声認識モデル（SenseVoice / Whisper）** で文字起こしします。音声は外部サーバーに送信しません。
日本語と中国語（普通話）に対応し、録音ボタン横のボタンでワンタップ切替できます。
サーバー不要の静的ファイルのみで動作し、データは端末内（IndexedDB）に保存されます。

## 使い方
1. 「設定」タブで 車両ID・評価者・6 つの種類 を入力して保存
2. 同じく「設定」で **モデルをダウンロード／読込**（初回のみ。Wi-Fi 推奨）
3. 「記録」タブで種類をタップ → 録音ボタン右の **日本語／中文** で言語を選ぶ → 赤い録音ボタンを **押している間だけ録音**、離すと保存
4. 保存後、裏で自動的に文字起こし（ヘッダーに進捗表示）。録音は続けて行えます
5. 「一覧」タブで表形式で確認・テキスト修正・再生・再変換 →「CSV出力」または「CSV+音声ZIP」

## 文字起こしモデル
| 設定 | モデル | サイズ | 特徴 |
|---|---|---|---|
| SenseVoice（初期値） | FunASR / FunAudioLLM SenseVoiceSmall (int8, sherpa-onnx 版) | 約240MB | 中国語・日本語とも高精度で高速。数秒の音声を1秒前後 |
| Whisper small | OpenAI Whisper small (int8) | 約250MB | 高精度。1件あたり数秒〜十数秒 |
| Whisper base | OpenAI Whisper base (int8) | 約80MB | 軽量だが誤変換が多い |

PC での計測例（4スレッド）：日本語3.2秒の音声 → SenseVoice 約0.6秒 / Whisper small 約5秒。
中国語5.6秒の音声 → SenseVoice「开饭时间早上9点至下午5点。」約1秒 / Whisper small「开放时间…」約13秒（1スレッド）。

- モデルは初回にダウンロードされ、ブラウザの Cache Storage に保存されます。
  2回目以降の起動では通信せず端末から読み込みます（ヘッダーに「端末から読込中」と表示）。
- **配布元**：設定で Hugging Face / hf-mirror.com（中国国内向けミラー）を切り替えられます。
  中国国内では huggingface.co に接続できないため hf-mirror.com を選んでください。
  なお、アプリ本体を置く GitHub Pages（github.io）も中国国内では不安定なため、中国で常用する場合はアプリの配置先も検討が必要です。
- **ホーム画面に追加して起動してください。** Safari のタブで使うと、7日間開かなかった場合に
  iOS がモデルと記録を自動削除することがあります（ホーム画面から起動したアプリは対象外）。
- 設定画面で各モデルのダウンロード状況の確認と、使っていないモデルの削除ができます。
- 文字起こしは録音と並行してバックグラウンドで順番に処理します。アプリを閉じて中断した分は次回起動時に再開します。
- Qwen3-ASR はブラウザで動く形式（ONNX）が公開されておらず、端末内では動かせないため対象外としています。
- ライブラリ（`lib/` に同梱）：[transformers.js](https://github.com/huggingface/transformers.js) 3.8.1（Apache-2.0）、
  [ONNX Runtime Web](https://github.com/microsoft/onnxruntime) 1.22.0-dev（MIT）。
  SenseVoice の前処理（Kaldi 互換 fbank・LFR・CMVN）と CTC デコードは `sensevoice-worker.js` に実装。

## 処理について
- 文字起こしは端末の CPU で行います。Service Worker が COOP/COEP ヘッダーを付与してクロスオリジン分離し、
  最大4スレッドで並列計算します（初回のみページが自動で1回開き直されます）。
- モデルのダウンロードに失敗した場合、録音した記録は「文字起こし待ち」のまま残ります。
  右上の表示（「モデル取得失敗」）をタップ →「モデルのダウンロードを再試行」で読み込めると自動で文字起こしします。
- 設定画面の使用量は、記録の音声サイズとダウンロード済みモデルのサイズをアプリで集計して表示します。

## 記録の番号
- 記録は **評価日（録音開始日）＋セッション番号＋セッション内の通し番号（No）** で管理します。
- セッション番号は 1 から始まり、「全記録を削除（次のセッションへ）」で +1 されます。No はセッションごとに 1 から振り直します。
- 個別に削除した記録の番号は欠番のままです（詰めません）。
- アプリの一覧には No のみ表示し、評価日・セッション番号は CSV にのみ出力します。
- 音声ファイル名も同じ体系です（例：`20261121_S02_001_車両挙動.m4a`）。

## 記録項目（CSV）
評価日・セッション・No・車両ID・評価者・種類・言語・録音開始・録音終了・録音時間(秒)・緯度・経度・テキスト・音声ファイル
（Excel で文字化けしない BOM 付き UTF-8）

## 公開方法（GitHub Pages）
1. GitHub のリポジトリ → Settings → Pages
2. Source: **Deploy from a branch**、Branch: 公開したいブランチ / フォルダ **/(root)** を選んで Save
3. 数分後に `https://knssng.github.io/simple-voice-memo/` で公開されます（HTTPS 自動）
4. iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」

## 注意点
- データとモデルは端末のブラウザ内にのみ保存されます。Safari の履歴・Web サイトデータを消去すると記録も消えるため、
  評価後は必ず CSV / ZIP を出力してください。
- アプリ更新時は `app.js` の `APP_VERSION`、`sw.js` の `VERSION`、`index.html` の `?v=` を上げてください。
