# 走行評価メモ

車両の実走評価中に、発生事象の「種類」を選んで音声でメモを残すための iPhone 向け Web アプリです。
文字起こしには **iPhone 標準の音声入力（キーボードの🎤）** を使います。
サーバー不要の静的ファイルのみで動作し、データは端末内（IndexedDB）に保存されます。

## 使い方
1. 「設定」タブで 車両ID・評価者・6 つの種類 を入力して保存
2. 「記録」タブで種類ボタンをタップ → 入力欄とキーボードが開く（この時刻が **開始時刻**）
3. キーボードの 🎤 を押して話す（話し終えたらキーボードの🎤以外の場所をタップ、または自動で止まります）
4. 「保存」を押す（この時刻が **終了時刻**）
5. 「一覧」タブで表形式で確認・テキスト修正 →「CSV出力」→ 共有シートから「ファイルに保存」や AirDrop、メールへ

テキストが空のまま保存すると、時刻と位置だけを記録できます（事象発生時刻のマーカーとして利用可）。

## 記録項目（CSV）
No・車両ID・評価者・種類・開始時刻・終了時刻・所要時間(秒)・緯度・経度・テキスト
（Excel で文字化けしない BOM 付き UTF-8）

## 事前に確認する iPhone の設定
- 設定 → 一般 → キーボード →「音声入力」を ON、「音声入力の言語」に日本語
- 位置情報を記録する場合は Safari の位置情報を許可

## 公開方法（GitHub Pages）
1. GitHub のリポジトリ → Settings → Pages
2. Source: **Deploy from a branch**、Branch: 公開したいブランチ / フォルダ **/(root)** を選んで Save
3. 数分後に `https://knssng.github.io/simple-voice-memo/` で公開されます（HTTPS 自動）
4. iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」

## 注意点
- データは端末のブラウザ内にのみ保存されます。Safari の履歴・Web サイトデータを消去すると記録も消えるため、
  評価後は必ず CSV を出力してください。
- アプリ更新時は `app.js` の `APP_VERSION`、`sw.js` の `VERSION`、`index.html` の `?v=` を上げてください。
