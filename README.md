# 走行評価メモ

車両の実走評価中に、発生事象の「種類」を選んで音声でメモを残すための iPhone 向け Web アプリです。
録音した音声は **端末内の Whisper（OSS 音声認識モデル）** で文字起こしします。音声は外部サーバーに送信しません。
サーバー不要の静的ファイルのみで動作し、データは端末内（IndexedDB）に保存されます。

## 使い方
1. 「設定」タブで 車両ID・評価者・6 つの種類 を入力して保存
2. 同じく「設定」で **モデルをダウンロード／読込**（初回のみ。Wi-Fi 推奨）
3. 「記録」タブで種類をタップ → 赤い録音ボタンを **押している間だけ録音**、離すと保存
4. 保存後、裏で自動的に文字起こし（ヘッダーに進捗表示）。録音は続けて行えます
5. 「一覧」タブで表形式で確認・テキスト修正・再生・再変換 →「CSV出力」または「CSV+音声ZIP」

## 文字起こしモデル
| 設定 | モデル | サイズ | 特徴 |
|---|---|---|---|
| 標準（初期値） | whisper-small (int8) | 約250MB | 日本語の精度が高い。数秒の音声で十数秒 |
| 軽量 | whisper-base (int8) | 約80MB | 速いが誤変換が多い |

- モデルは初回に Hugging Face からダウンロードされ、ブラウザ内にキャッシュされます。以降は通信なしで動作します。
- 文字起こしは録音と並行してバックグラウンドで順番に処理します。アプリを閉じて中断した分は次回起動時に再開します。
- ライブラリ: [transformers.js](https://github.com/huggingface/transformers.js) 3.8.1（`lib/` に同梱、Apache-2.0）

## 記録項目（CSV）
No・車両ID・評価者・種類・録音開始・録音終了・録音時間(秒)・緯度・経度・テキスト・音声ファイル
（Excel で文字化けしない BOM 付き UTF-8）

## 公開方法（GitHub Pages）
1. GitHub のリポジトリ → Settings → Pages
2. Source: **Deploy from a branch**、Branch: 公開したいブランチ / フォルダ **/(root)** を選んで Save
3. 数分後に `https://knssng.github.io/simple-voice-memo/` で公開されます（HTTPS 自動）
4. iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」

## 注意点
- データとモデルは端末のブラウザ内にのみ保存されます。Safari の履歴・Web サイトデータを消去すると記録も消えるため、
  評価後は必ず CSV / ZIP を出力してください。
- アプリ更新時は `app.js` の `APP_VERSION`、`sw.js` の `VERSION`、`index.html` の `?v=` を上げてください。
