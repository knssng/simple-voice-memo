# 走行評価メモ（音声メモ Web アプリ）

車両の実走評価中に、発生事象の「種類」を選んで音声でメモを残すための iPhone 向け Web アプリです。
サーバー不要の静的ファイルのみで動作し、データは端末内（IndexedDB）に保存されます。

## 機能
- 事象の種類ボタン 6 個（大きめ）。内容は「設定」タブで自由に登録
- 録音ボタンを **押している間だけ** 録音、離すと停止（0.4 秒未満の押下は誤タップとして破棄）
- 音声をテキスト化（ブラウザ標準の音声認識 / 日本語）＋音声ファイルも保存
- 記録項目：No・車両ID・評価者・種類・録音開始・録音終了・録音時間(秒)・緯度・経度・テキスト・音声ファイル名
- 「一覧」タブで表形式表示、テキストの手修正、音声再生、地図表示、削除
- CSV 出力（Excel で文字化けしない BOM 付き UTF-8）／音声 ZIP 出力（CSV + 音声ファイル）
- 走行中に画面が消えないようにする設定（iOS 16.4 以降）

## 公開方法（GitHub Pages）
1. GitHub のリポジトリ → Settings → Pages
2. Source: **Deploy from a branch**、Branch: 公開したいブランチ（例: `main`）/ フォルダ **/(root)** を選んで Save
3. 数分後に `https://knssng.github.io/simple-voice-memo/` で公開されます（HTTPS 自動）

## iPhone での使い方
1. Safari で上記 URL を開く → 共有ボタン →「ホーム画面に追加」
2. 「設定」タブで 車両ID・評価者・6 つの種類 を入力して保存
3. 「記録」タブで種類をタップ → 赤い録音ボタンを押したまま話す → 離すと保存
4. 「一覧」タブで確認・修正 →「CSV出力」/「音声ZIP出力」→ 共有シートから「ファイルに保存」や AirDrop、メールへ

初回はマイク・音声認識・位置情報の許可を求められます。すべて「許可」してください。

## 注意点
- 音声認識は iOS の音声入力を利用します。端末や電波状況によっては通信が必要です。
  圏外区間では音声ファイルのみ残り、テキストは空欄になる場合があります（一覧で後から手入力可能）。
- 文字起こしが動かない場合は「設定」→「音声ファイルを保存する」を OFF にしてお試しください
  （iOS でマイクの同時利用が競合する場合への対処）。
- データは端末のブラウザ内にのみ保存されます。Safari の履歴・Web サイトデータを消去すると記録も消えるため、
  評価後は必ず CSV / ZIP を出力してください。
- 不具合時は「設定」タブ下部の **診断ログ** を確認してください（録音形式・音声サイズ・エラー内容が記録されます）。
- アプリ更新時は `sw.js` の `VERSION` を上げてください。
